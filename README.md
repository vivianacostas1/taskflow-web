# 🚀 TaskFlow Frontend

Aplicación web para la gestión eficiente de proyectos y tareas.

## 🛠 Stack tecnológico
- React 18, Vite, TypeScript, Tailwind CSS v4, Axios.

## 🚀 Instalación local
1. Clona el repositorio: `git clone https://github.com/vivianacostas1/taskflow-web`
2. Instala dependencias: `npm install`
3. Crea un archivo `.env` basado en `.env.example`.
4. Inicia el servidor: `npm run dev`
